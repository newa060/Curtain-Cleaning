# Curtain Cleaning Brisbane

A modern, responsive Next.js application for **Curtain Cleaning Brisbane**, built using Next.js 14 (App Router), TypeScript, and Tailwind CSS based on Google Stitch design specifications.

## 🚀 Features

- **In-Situ Curtain Cleaning Showcase**: Gentle on-site steam and ultrasonic cleaning directly on window tracks.
- **Instant Pricing Estimator**: Interactive calculator for curtain panels, fabric blends, and subtropical mould treatments.
- **5-Step Booking Wizard**: Multi-step booking experience with instant estimate feedback.
- **Responsive Layout**: Designed for mobile, tablet, and desktop viewports.
- **SEO & Performance**: Optimized App Router architecture, Google Fonts (`Playfair Display` & `Plus Jakarta Sans`), and metadata.

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Build for Production

```bash
npm run build
npm start
```
